# 🚀 Odak İstasyonu V41

Spotify API entegrasyonu ile geliştirilmiş, odaklanma sürenizi müzikle yönetmenizi sağlayan profesyonel bir otomasyon aracıdır.

## 🛠️ Proje Bileşenleri

### 1. 🧠 main.py
Uygulamanın beynidir. Spotify PKCE protokolü ile şifresiz/güvenli bağlantı sağlar ve odaklanma süresi bittiğinde müziği otomatik durdurur.

### 2. 🛡️ .gitignore
Güvenlik kalkanıdır. `.cache`, `focus_settings.json` ve `.idea/` gibi kişisel veya gereksiz dosyaların genel erişime açılmasını engeller.

### 3. 📦 requirements.txt
Projenin çalışması için gerekli olan `spotipy`, `colorama` ve `art` gibi kütüphanelerin listesini barındırır.

## 🔒 Güvenlik Notu
Bu proje kullanıcı gizliliğini ön planda tutar. Hiçbir hassas veri kod içerisinde barındırılmaz ve kişisel dosyalar GitHub'a yüklenmez.
